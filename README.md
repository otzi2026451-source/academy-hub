# Academy Hub 4.0 — информационное табло Академии

**Интерфейс:** телевизионное табло 16:9, шесть учебных групп, КРД и ОТЗИ, рейтинги, спорт, объявления и календарь дней рождения.

**Разработчик (подпись на сайте):** курсант Пренебек Н., ОТЗИ-1.

## Открыть

- **Обычная версия и админ-панель:** `https://otzi2026451-source.github.io/academy-hub/`
- **Samsung TV:** `https://otzi2026451-source.github.io/academy-hub/?tv=1#dashboard`
- Для входа нажмите «Управление» в левом меню и войдите по Email/Password существующего администратора Supabase.
- Для полноэкранного интерфейса ТВ сайт убирает собственное меню и масштабируется до 1920 × 1080. Выход на *аппаратный* полноэкранный режим зависит от браузера Samsung TV.

## Возможности

- **Учебный топ-10** и **общий спортивный топ-5**, отдельные секции по рукопашке, борьбе, лёгкой атлетике, футболу и волейболу.
- **Расписания шести групп** и **оценки по каждой группе** автоматически переключаются по 15-секундному таймеру.
- **Активная и следующая пара** выделяются с учётом времени Алматы и настроенной продолжительности занятия (по умолчанию 90 минут). Кабинеты указываются в строках расписания, если известны.
- **Большие группы:** оценки показываются по семь фамилий за раз; при очередном возвращении группы появляется следующая страница, поэтому не нужно снижать размер шрифта ради 25 строк.
- **Дни рождения:** сегодня и ближайшие даты; публичная таблица `birthday_public` автоматически выбирает только разрешённые поздравления за текущий день.
- **Объявления:** обычное / важное / срочное, при необходимости — срок действия.
- **История:** предыдущие 50 версий `app_state` архивируются серверным триггером в `app_state_history`; доступ только у текущего администратора.
- **Резервная копия:** кнопки экспорта JSON и скачивания CSV-шаблона в админ-панели.
- **ИИ:** чат с вложениями TXT, CSV, DOCX, XLSX, XLS, PPTX, PDF с текстовым слоем, JPG, PNG и WebP. Импорт распознаёт расписания `KRD1`…`OTZI2`, оценки групп, спортивные секции, общие рейтинги и объявления. Перед публикацией администратор проверяет результат и явно подтверждает сохранение.
- **Отказоустойчивость:** телевизор сохраняет последние загруженные данные на экране при временном обрыве сети и показывает состояние подключения.

## Как ввести расписание

В разделе **Управление → Расписание групп** заполните поле соответствующей группы (по одной паре на строку):

```text
08:30 | Математика · кабинет 301
10:20 | Физика · кабинет 204
12:10 | Информационная безопасность · кабинет 212
```

Укажите достоверные занятия, длительность пар и нажмите **«Сохранить на все экраны»**. Табло синхронизируется примерно каждые 15 секунд.

Оценки вводите строками в формате **ФИО | балл от 0 до 100**. Фамилии не вымышляются автоматически.

## Инфраструктура

- **Статика:** `index.html`, `academy4.js`, `academy4.css`, `config.js`.
- **Хранилище:** Supabase `app_state`, `cadets`, `birthday_public`, `app_state_history`.
- **Доступ:** Supabase Auth с серверной проверкой права `can_access_academy()`, закрытым доступом к `app_state` и `birthday_public` и проверкой UID администратора. Не помещайте пароль, служебные JWT, Gemini API key и `service_role` в GitHub или `config.js`.
- **Функция Gemini:** `supabase/functions/parse-document/index.ts`, развернута отдельно в Supabase; требует действительных секретов `GEMINI_API_KEY` и `ADMIN_USER_UID`. Текущий серверный код проверяет JWT самостоятельно. Работоспособность зависит от доступности модели, квот и биллинга Google.
- **Автоматические проверки:** `scripts/verify-site.mjs` и `scripts/browser-smoke.mjs` в GitHub Actions, браузерный тест использует исключительно вымышленные данные.

## Важно: доступ к сайту

**Этот репозиторий и GitHub Pages пока публичные, но данные в Supabase закрыты.** На сайте работает обязательный экран входа, а `app_state` и `birthday_public` больше недоступны анонимным пользователям. Серверная функция `can_access_academy()` разрешает доступ к данным только существующему владельцу-администратору. В браузере Samsung TV сохраняется сессия для автоматического входа; любой, кто физически получит доступ к разблокированному телевизору или его хранилищу, потенциально сможет воспользоваться текущим сеансом.

Для полного сокрытия самого сайта и его HTML/JavaScript необходимо переместить хостинг за Cloudflare Access (или аналогичный шлюз). Одно лишь `Private` в GitHub не закрывает GitHub Pages автоматически. Перед использованием персональных и служебных данных также требуется разрешение ответственных за их обработку. Просто перевести репозиторий в `Private` недостаточно, а GitHub Pages может перестать работать на некоторых тарифах.

Не загружайте в Gemini закрытую или секретную информацию без разрешения ответственного лица. Не храните личные данные курсантов в открытом репозитории.


## Вход после включения защиты

1. Откройте обычный сайт или ссылку `?tv=1` на Samsung TV. Первым экраном будет форма Email/Password.
2. Введите **существующие** данные входа администратора Supabase, ранее использовавшиеся в панели управления. Новый пароль не создаётся и не публикуется.
3. После успешной серверной проверки появится табло. Обновление страницы на том же устройстве восстанавливает защищённый сеанс через refresh token.
4. Для выхода на компьютере используйте пункт управления и кнопку «Выйти»; для полного отзыва сессий используйте управление Supabase Auth.

Ни адрес сайта, ни анонимный ключ Supabase из `config.js` сами по себе не дают доступ к данным. **Не оставляйте административную сессию на телевизоре, доступном посторонним:** рекомендуется отдельная роль только для просмотра при следующем развёртывании.


## Academy Hub 5.0 — недельный режим и спортивная аналитика

**Недельное расписание:** открой «Управление», раскрой «Недельное расписание», выбери одну из шести групп и день недели. Вводи строки `08:30 | Предмет · кабинет`, затем нажми основную кнопку «Сохранить на все экраны». Табло автоматически выбирает день по часовому поясу `Asia/Almaty`. Если этот день пуст, применяется прежнее однодневное расписание группы. Время и актуальность проверяются администратором.

**Оценки:** существующий редактор `Имя | Балл` заполняется отдельно для каждой группы. «Динамика успеваемости» показывает средние баллы на основе реально введённых оценок; историю формируют предыдущие сохранения. Усложнённый профиль ОТЗИ отдельно отмечен в описании подготовки, но искусственных балльных коэффициентов нет.

**Спорт:** в «Матчи» вводи `16.10.2026 | Футбол | KRD1 | OTZI1 | 3:2`. Таблица начисляет 3 очка за победу и 1 за ничью. Спортивный лидер месяца рассчитывается только по матчам за текущий месяц. На табло также чередуются секции, календарь мероприятий и достижения примерно раз в 20 секунд, без управления мышкой.

**Мероприятия:** строки `18.10.2026 | Соревнования | Спортзал`; табло показывает ближайшие события и сколько дней осталось. «Достижения» заполняются форматом `Награда | Курсант или группа | Дата`. Публикуй только разрешённые сведения.

**Excel:** в «Массовый импорт Excel» загрузи XLSX/XLS (максимум 6 МБ). Для каждого направления нужен отдельный лист, названный `KRD1`, `KRD2`, `KRD3`, `KRD4`, `OTZI1`, `OTZI2`. Расписание: колонки `День`, `Время`, `Предмет`. Оценки: `ФИО`, `Балл` (0–100). Система покажет предварительный отчёт; изменения публикуются только после подтверждения. Ранее заполненные другие группы не стираются.

**Контроль качества:** раздел проверяет отсутствие расписания и оценок по группам, повторяющиеся начала пар, неверные даты и сомнительные записи матчей. Замечания требуют ручной проверки; ИИ не должен выдумывать закрытые данные.

**Samsung 24/7:** при поддержке браузера используется Screen Wake Lock API, сведения обновляются автоматически, а смещение изображения не более 1 пикселя каждые 5 минут помогает уменьшить риск выгорания. **Сайт не может автоматически запустить браузер после включения Samsung TV**: автозапуск зависит от настроек ТВ или выбранного kiosk-приложения.

### Разделение ролей

- **Администратор** — исходная разрешённая учётная запись. Может редактировать и видеть реестр курсантов.
- **TV / Viewer** — отдельная подтверждённая учётная запись Supabase Auth, которая читает только `app_state` и сегодняшние разрешённые поздравления. Не видит редактор, реестр и ИИ-центр, не может менять базу.
- Для добавления TV-аккаунта: сначала создай/подтверди учётную запись через Supabase Auth, затем в разделе «Управление → Права Samsung TV» введи email и нажми «Разрешить просмотр». Там же можно отозвать доступ. `academy_grant_viewer` проверяет роль администратора на стороне сервера.
- **Не используй административный пароль на общедоступном телевизоре.** Выделенная роль просмотра специально для этого и добавлена.

**Граница защиты:** GitHub Pages и исходный код репозитория по-прежнему публичны. Доступ к самим сохранённым данным охраняют вход Supabase, серверные RPC и RLS. Полное сокрытие HTML/JS требует переноса сайта на закрытый хостинг или настройки шлюза вроде Cloudflare Access на собственном домене; изменить видимость GitHub-репозитория текущий коннектор не позволяет.

## Academy Hub 6.0 — новая админ-панель

В обычной версии сайта открой «Управление». Теперь это **отдельная панель с боковыми вкладками**, поиском, таблицей заполнения шести групп и прикреплённой кнопкой сохранения. Доступные вкладки: обзор, расписание, оценки и лидеры, спорт, мероприятия, достижения, дни рождения, реестр, ИИ, Excel, качество, черновики, доступы, история и предпросмотр Samsung TV.

### Роли

- **Администратор:** единственный исходный владелец аккаунта Supabase. Может изменять реальные данные, назначать читателей и редакторов, просматривать реестр и публиковать.
- **Редактор:** отдельная подтверждённая учётная запись. Может войти в собственный «Кабинет редактора» и отправить черновик объявления/мероприятия на утверждение. **Не может сам публиковать**, изменять табло, просматривать реестр или запускать ИИ-импорт.
- **Samsung TV / viewer:** только просмотр информационного табло через защищённый вход; без администрирования.
- Для выдачи роли сначала создай/подтверди отдельного пользователя в Supabase Auth, затем введи его email в разделе «Права доступа». Назначение и отзыв проверяются серверной функцией. Не используй пароль администратора на общедоступном телевизоре.

### Черновики и запланированная публикация

В разделе «Черновики» укажи название, при необходимости дату и время публикации **по времени Алматы**. Серверная функция Supabase помещает черновик в очередь; `pg_cron` запускает `academy_publish_due()` **раз в минуту**, даже если админ-панель закрыта. Только администратор может назначить публикацию или одобрить черновик редактора. История предыдущего состояния сохраняется автоматически. Допустима задержка около минуты относительно выбранной отметки.

### ТВ-экран

- Автоматический выбор текущего дня недели и расписания группы. Вечером после 19:00 по Алматы допускается предварительный показ завтрашнего расписания, если оно задано.
- Индикатор оставшегося времени занятия — из заданной продолжительности пары.
- Внизу широкая информационная полоса переключает объявление, события и подтверждённых лидеров примерно каждые 12 секунд. Срочное объявление остаётся на первом плане.
- Курсант недели, курсант месяца и лучшая группа месяца вводятся вручную по подтверждённым данным. Для их определения требуются результаты с датами; система не выдумывает победителей.
- Предпросмотр телевизора: вкладка «Предпросмотр ТВ» в админ-панели открывает 16:9-кадр из того же защищённого сайта.
- Если Samsung TV поддерживает Screen Wake Lock и kiosk-настройки, экран может оставаться активным. Автоматическое включение браузера после включения телевизора требует настройки самого ТВ или kiosk-приложения.

### ИИ Gemini

Функция `parse-document` обновлена: вместо моделей Gemini 2.5, возвращавших 404, используются доступные модели Gemini 3.x с резервными вариантами и понятными ошибками по квотам/нагрузке. Работа всё равно зависит от действующего `GEMINI_API_KEY`, доступа к API и квот Google. Файлы и результаты ИИ не публикуются автоматически без подтверждения администратора.

### Безопасность

GitHub Pages по-прежнему размещает *исходные HTML/JS публично*, но Supabase RLS закрывает табло, реестр и очередь черновиков без авторизации. Полное закрытие даже самой страницы входа требует защищённого хостинга или внешнего шлюза доступа. Не загружайте сведения, не разрешённые к публикации, и не помещайте API-ключи или списки реальных курсантов в открытый репозиторий.


## Academy Hub 7.0 — безопасность, диагностика и контроль публикаций

Новые пункты доступны **после авторизации администратора** во внутреннем меню «Управление». Реальные персональные записи остаются только в Supabase с ограниченным доступом.

- **Безопасность:** показывает устройства, которые *подключались к Academy Hub* с подтверждённой ролью, время первого обращения и последнего сигнала. Это **не** полный список всех сессий Supabase Auth. Кнопка «Отозвать аккаунт» снимает роль редактора или TV-пользователя для **всех устройств** этой учётной записи; администратор не может отозвать самого себя. Смена роли применяется к SQL RLS сразу, приложение дополнительно проверяет роль раз в минуту. Отзыв отдельного токена устройства не реализован.
- **Диагностика:** ручная проверка базы и прав, состояние сети и последнего обновления табло, сообщения об ошибках импорта и JavaScript в текущем браузере. Реальный тест Gemini выполняется **только после отдельного нажатия**, без передачи данных курсантов; может расходовать токены API.
- **Календарь:** список событий, экзаменов, зачётов и соревнований, сгруппированных по категориям, с отсчётом до ближайшей даты. Допустимые строки: `20.10.2026 | Экзамен по физике | Учебный корпус | 09:00`, время необязательно. Используется часовой пояс Алматы; названия и место публикуются только при наличии разрешения.
- **Проверка изменений:** перед обычным сохранением админ-панель показывает список изменённых разделов. Можно исключить отдельные разделы, увидеть повторы фамилий, ошибок дат и пересечения занятий. Критические совпадения времени блокируют сохранение. Импорт Excel также имеет отдельную локальную проверку повторов (кнопка «Найти дубликаты») перед подтверждением.
- **Поиск курсантов:** только у администратора, по имени, группе и коду в *существующем закрытом реестре* с дополнительными учебными и спортивными результатами, где они уже введены. Данные не передаются внешнему поисковику и не выводятся на ТВ.
- **Samsung 24/7:** индикатор последней синхронизации и состояния сети, отображение ближайшего события, режим компактности при переполнении блоков; при пропадании интернета уже открытое табло продолжает показывать последние полученные данные. **Локальный кэш персональных данных на диск не создаётся**; после полной перезагрузки без сети потребуется соединение.
- **Резервные копии:** ежедневная задача `academy-hub-state-backup-daily` в `pg_cron` снимает снимок `app_state` в закрытую таблицу `academy_state_backups`, хранит последние 35 копий и даёт администратору скачать/восстановить их. Перед восстановлением текущая версия архивируется отдельно. Начиная с 7.1, отдельный столбец `cadets_snapshot` также содержит защищённый снимок реестра курсантов; его восстановление требует особого подтверждения. Штатные бэкапы PostgreSQL всё равно рекомендуются.

### Обязательные ограничения

Статические файлы GitHub Pages пока доступны публично, но чтение данных через Supabase защищено RLS и проверкой авторизации. Не используйте публичный хостинг для служебной или закрытой информации без утверждённого защищённого шлюза. Журнал устройств хранит технический идентификатор браузера и примерную метку устройства, не физическое местоположение и не IP.


## Academy Hub 7.1 — обновление надёжности и безопасности (16.10.2026)

- **Авторизация:** raw `app_state` доступен только владельцу-администратору; роль Samsung TV получает ограниченную проекцию `academy_tv_board()`. Даже имея разрешённую учётную запись TV, нельзя напрямую читать внутренние поля состояния табло через SQL API.
- **Сеансы:** для компьютера админ-сессия хранится в `sessionStorage`, для отдельной TV-страницы — в `localStorage`. Встроенный TV-предпросмотр использует действующий токен родительской вкладки и не копирует долговременный refresh-token. Проверка доступа повторяется примерно раз в минуту.
- **Устройства:** можно отзывать конкретную зарегистрированную сессию, если Supabase выдал JWT `session_id`. Сервер сверяет `session_id` с `academy_revoked_sessions`. Владелец не может случайно отозвать собственную сессию через эту кнопку. Отзыв аккаунта TV/редактора доступен отдельно.
- **Черновики:** администратор видит фактические поля и значения перед публикацией редакторского черновика, должен открыть подробности и подтвердить просмотр. Это не освобождает от обязанности проверить данные.
- **Сохранение:** выборочная публикация не сбрасывает неотмеченные несохранённые поля в браузерной форме. Проверка пересечений учитывает продолжительность пар, а не только одинаковое начало. Импорт Excel блокируется при дубликатах ФИО в листах и пересечениях занятий.
- **Время:** часы, дни недели и расписание используют `Asia/Almaty`; недельное расписание не заполнено — на табло показано состояние «НЕ ЗАПОЛНЕНО», старые образцы не объявляются занятиями на сегодня.
- **Gemini:** функция `parse-document` v8 исключает устаревшие модели 2.5 из списка, ограничивает число попыток и таймаут. Доступность сервиса остаётся зависимой от Google и его квот.
- **Копии:** ежедневная функция сохраняет **табло и ограниченный реестр** в RLS-таблице, оставляя 35 последних снимков. Восстановление реестра требует два последовательных подтверждения, сначала создаёт отдельный снимок текущего состояния.
- **Тестирование:** Chromium на нескольких разрешениях, сценарии администратора/редактора/TV, выборочное сохранение без потери черновика и 132 вымышленные записи групп (25×4, 14, 18). В публичный репозиторий реальные данные не добавлялись.

**Проверить с реальным оборудованием:** 24-часовую работу браузера Samsung TV, сохранение сеанса после перезагрузки телевизора и восстановление реальных данных из резервной копии отдельно, на санкционированном закрытом стенде. Текущий GitHub Pages публичен как веб-сервер: закрыта БД, но не сам HTML/JavaScript. Полностью закрытый веб-доступ требует отдельного шлюза с контролируемым адресом и настройками владельца.


## Academy Hub 8.0 — безопасная подготовка данных (16.10.2026)

**Создано в Supabase, без затрагивания реальных записей:**

- `academy_groups`: шесть групп и вместимость `25+25+25+25+14+18=132`.
- `academy_grade_records`: связанные с кодом курсанта оценки по дисциплинам и датам; изменения пишутся в закрытую `academy_grade_audit`.
- `academy_import_batches`: двухэтапный мастер загрузки реестра, изначально только статус `prepared`, без записи в `cadets`. Проверяются дубликаты ФИО/кодов, группа, дата, допустимая численность; существующий непустой реестр импорт перезаписать **не может**. Для реального импорта требуется подтверждение `IMPORT_CONFIRMED` и права администратора. Подготовленные, но не утверждённые пакеты автоматически очищаются через 24 часа; после публикации дублирующие строки удаляются из черновика.
- `academy_tv_health`: техническая информация о Samsung TV (время последнего обращения, версия приложения, разрешение экрана, статус видимости) без оценок или ФИО. Только администратор читает отчёт, только проверенный пользователь TV/admin может отправить heartbeat.
- `academy_sandbox.cadets`: **132 вымышленные записи**, техническая схема без доступа для `anon`/`authenticated` и без передачи в рабочий реестр. `academy_sandbox_report()` показывает проверку по группам только администратору.
- `parse-document` v10: проверка доступности моделей Gemini по отдельной кнопке через защищённый `mode=probe`. Сам тест не отправляет содержимое документов Google; ответы Gemini и импорт по-прежнему требуют настоящего API-ключа.

**Админ-панель:** вкладки «Импорт 132 курсантов», «Мониторинг Samsung TV», «Тестовый стенд», «ИИ: проверка моделей». Учётные записи и доступы остались прежними.

**Отдельный демонстрационный сайт:** `academy8-sandbox.html` содержит только фиктивные данные, работает без сети и не подключается к Supabase. Используется для проверки интерфейса и проверок ошибок; не является вторым рабочим хостингом.

**Полное закрытие самого сайта — не завершено**, потому что GitHub Pages остаётся публичным, а подключённого Cloudflare Access/закрытого хостинга нет. См. `docs/ACADEMY_8_PRIVATE_HOSTING.md`.
